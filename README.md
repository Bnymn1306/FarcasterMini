# BasedMem - Meme Coin Launch Platform

Launch meme coins in under 60 seconds on Base blockchain with Farcaster Mini App integration.

## Features

- **Quick Tokenize**: Paste any Warpcast URL to tokenize viral Farcaster casts automatically
- **Bonding Curve Trading**: Linear bonding curve for automated pricing
- **Badge System**: NFT achievement awards for milestones
- **Portfolio Tracking**: Monitor your meme coin holdings
- **Price Alerts**: Get notified via Farcaster when tokens hit targets

## Smart Contracts

- **TokenFactory**: `0x6E3c21d02A56aE514c489D6066C389Bae99e2C39`
- **BMEM Platform Token**: `0x6cDa3b61128aDeB94FFC8ec124D18bc099E8eb3d`
- **Network**: Base (Ethereum L2)

## Tech Stack

- Frontend: React + TypeScript + Vite
- Backend: Express.js + PostgreSQL
- Blockchain: ethers.js + Hardhat
- UI: shadcn/ui + Tailwind CSS
- Social: Farcaster SDK + Neynar API
